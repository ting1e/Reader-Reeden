云端存储配置

用于远程书库和进度同步，JSON 格式。

查看 JSON 示例与字段说明 
{
  "accessKeyId": "你的 AccessKey ID",       // 必填
  "secretAccessKey": "你的 Secret Access Key", // 必填
  "endpoint": "https://s3.us-east-1.amazonaws.com", // 必填，含 https://
  "bucket": "my-book-bucket",              // 必填，存储桶名
  "region": "us-east-1",                   // 可选，部分服务商可留空
  "prefix": "reader/"                      // 可选，桶内路径前缀
}

书籍存于 prefix + books/，进度存于 prefix + book_progress/，字体存于 prefix + fonts/。
